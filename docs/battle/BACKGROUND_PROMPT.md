# Background-only generation

Built-in imagegen edit tool. Input: user-provided approved battle reference. Output: `public/assets/battle/backgrounds/courtyard-premium-v1.png`.

Edit the provided approved Three Kingdoms battle reference into ONE CLEAN EMPTY BATTLEFIELD BACKGROUND asset. Preserve its composition, mature premium painted fantasy Chinese art, perspective, daylight color palette, mountains and sky above the gray stone fortress wall with blue tiled roofs and central red gate, flowering cherry branches in the upper corners, stone plaza paving and subtle carved dragon medallion at center ground, small fire braziers only at extreme lower left and lower right edges. Remove EVERY character, weapon, portrait, shadow under a character, nameplate, health bar, rage bar, all text, all numbers, every UI header, button, gold UI frame and footer overlay. Seamlessly reconstruct the environment behind removed items. This is a landscape 16:9 runtime game BACKGROUND ONLY: no UI, no people, no creatures, no flags containing readable letters, no game screenshot labels, no mockup. The floor must be continuous and clear across the entire lower two thirds to place 12 animated characters and a separate runtime HUD over it. Do not bake any interface into this asset.
