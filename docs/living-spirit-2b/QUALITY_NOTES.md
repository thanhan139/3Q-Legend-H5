# VISUAL QUALITY / PRODUCTION HONESTY

- Dragon animation for Quan Vũ uses an individually illustrated 16-frame emerald dragon GIF as the original moving visual basis; full independent dragon anatomy rig is **not included**.
- Triệu Vân and Lữ Bố use recolored versions of that frame-by-frame dragon motion with distinctive lightning/flame layers; no claim of separately authored geometry.
- Hạc Thiên Cơ and Bướm Hoa Nguyệt use SVG/vector compositing with changing wing shapes and independently moving particles; highly stylized, different aesthetic from the painted dragon.
- Idle motion is actual content variation per frame. Selected/Power Up add transition overlays without independent cinematic action sequences.
- UI mockups in older packages were illustrative only. Never use drawn text/levels as game state.
- Demo previews are GIF for review only, not intended as runtime texture. PNG spritesheet is the integration source.
- Art cohesion/edge aliasing still requires an in-engine Visual QA gate; do not present as final AAA animation.
- Source image for dragon is a model-generated sprite animation from this project. All other PNG layers are generated in code using the frame basis and original vector drawing.
